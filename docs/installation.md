# Installation

## Requirements

- PHP 8.4 or newer
- Composer

## Create a project

```bash
composer create-project nqai/nqphp-site my-app
```

Or require the framework directly:

```bash
composer require nqai/nqphp
```

## First run

```bash
bin/console serve
```

The development server listens on `http://localhost:8000` by default.
